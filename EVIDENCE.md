## 8. Pricing and Usage Consistency

A pricing test request was submitted with:

```text
API calls: 10
Input tokens: 1000
Cached input tokens: 400
Output tokens: 200
Reasoning tokens: 100
```

Total AI token usage:

```text
1000 + 200 + 100 = 1300
```

The cached input tokens were included in usage but priced using the lower cached-input rate.

Reasoning tokens were treated as output-priced tokens.

The generated usage response reported:

```text
API calls used: 10
AI tokens used: 1300
```

The estimated cost was returned as an integer number of cents.

Expected pricing behavior:

```text
Cached input → cheaper input pricing
Reasoning tokens → output pricing
Money → integer cents
```

Result:

PASS
